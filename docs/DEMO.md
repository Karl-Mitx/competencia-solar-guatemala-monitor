# Guion de demostración de diez minutos

La demo debe mostrar un flujo corto y verificable con los datos sintéticos cargados.

| Tiempo | Escena | Evidencia |
|---:|---|---|
| 0:00-0:45 | Problema y propósito | Solaris centraliza granjas, energía e impacto de los 22 departamentos. |
| 0:45-2:00 | Panorama nacional | Indicadores, tendencia real/esperada, familias, CO₂, ranking y alertas. |
| 2:00-3:00 | Mapa | Zoom, desplazamiento, colores por departamento, popup y ficha de una granja. |
| 3:00-4:15 | Inventario | Catálogo de paneles, edición de cantidades y capacidad recalculada. |
| 4:15-5:15 | Generación | Registro mensual, validación de mes cerrado y actualización de CO₂. |
| 5:15-6:15 | Alerta | Abrir una alerta demo con esperado, real, desviación y estado; superar 80 % para resolverla. |
| 6:15-7:30 | Reporte | Comparación departamental y descarga CSV. |
| 7:30-8:45 | Proyección | Elegir granja, generar horizonte, explicar media diaria de tres meses y mostrar comparación posterior. |
| 8:45-9:35 | API | Abrir `/api-docs` y consultar departamentos, estadísticas y generación filtrada. |
| 9:35-10:00 | Arquitectura y cierre | Laravel, MySQL, servicios centralizados, pruebas y próximos pasos de despliegue. |

Antes de la evaluación hay que sustituir el usuario demo local por credenciales privadas del entorno publicado, verificar una URL externa con dominio y confirmar los roles reales de ambos integrantes.
