# Equipo de Solaris

La competencia admite una pareja. El equipo acordó trabajar el repositorio con propiedad y reconocimiento **50/50**:

- ambos integrantes tendrán acceso de escritura al mismo repositorio;
- ambos aparecerán como autores y revisores de cambios relevantes;
- el porcentaje representa el acuerdo de responsabilidad del equipo, no una regla automática sobre la cantidad de commits;
- cada integrante debe poder explicar la arquitectura, los cálculos, la API, la interfaz y la demostración.

La implementación se coordina desde la rama de trabajo `codex/solaris`. Para mantener el acuerdo:

1. Cada integrante crea una rama con su nombre o funcionalidad y abre un Pull Request.
2. La otra persona revisa el Pull Request antes de integrarlo.
3. Los avances se describen en issues o Pull Requests para que el historial muestre la participación de ambos.
4. No se comparten contraseñas ni tokens; cada cuenta usa sus propias credenciales de GitHub.
